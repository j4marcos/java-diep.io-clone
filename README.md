# java-diep.io-clone

clone do jogo http://diep.io/

programa usando texnicas de concorrencia e sockets para a disciplina de PROGRAMAÇÃO CONCORRENTE E DISTRIBUÍDA

funcionalidades:


multijogador 
salas de partidas
painel de admin de visualização de threads e sockets ativos, e estatisticas do jogo

# regras

- se manter muito simples: esse é um projeto didatico de java o codigo precisa ser muito simples e claro
- preferir usar as funções ensinadas nos conteudos da disciplina
- evitar usar libs de alto nivel com soluções já prontas
